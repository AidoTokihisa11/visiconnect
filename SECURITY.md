# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in VisioConnect, please help us protect our users by reporting it responsibly.

### How to Report

1. **DO NOT** open a public issue
2. Send details to the repository owner via GitHub private message or create a private security advisory
3. Include:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

### What to Expect

- We will acknowledge receipt within 48 hours
- We will investigate and provide updates
- We will credit you in the fix (if desired)

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Security Best Practices

When using VisioConnect:

- Keep your dependencies up to date
- Never commit sensitive data (.env files)
- Use strong passwords and API keys
- Enable HTTPS in production
- Regularly review access logs

## Disclosure Policy

- We will investigate all reports
- Security fixes will be released as soon as possible
- Credits will be given to responsible reporters

Thank you for helping keep VisioConnect secure!
