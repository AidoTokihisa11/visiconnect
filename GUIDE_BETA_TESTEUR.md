## ✅ 1. Accéder à la plateforme et créer un compte

### 🌐 A. Se rendre sur la plateforme

Ouvrez votre navigateur (de préférence **Google Chrome** ou **Firefox** à jour) et rendez-vous sur :

👉 **[https://visioconnect-1.vercel.app/](https://visioconnect-1.vercel.app/)**

> ⚠️ Évitez Internet Explorer ou les navigateurs d'entreprise avec des restrictions réseau — ils peuvent bloquer les connexions vidéo.

---

### 👤 B. Créer votre compte

La création d'un compte est obligatoire pour accéder aux salles de réunion. Deux chemins s'offrent à vous.

#### Méthode 1 — Connexion via Google ou GitHub *(recommandée, 30 secondes)*

1. Sur la page d'accueil, cliquez sur **"Se connecter"** en haut à droite.
2. Choisissez **"Continuer avec Google"** ou **"Continuer avec GitHub"**.
3. Autorisez l'accès dans la fenêtre qui s'ouvre.
4. Vous êtes connecté — vous arriverez directement sur votre tableau de bord.

#### Méthode 2 — Inscription par e-mail *(si vous préférez ne pas utiliser Google/GitHub)*

1. Cliquez sur **"Se connecter"** → **"Créer un compte"**.
2. Saisissez votre adresse e-mail et choisissez un mot de passe.
3. Un **code à 6 chiffres** vous sera envoyé à cette adresse dans les 2 minutes.
4. Recopiez ce code dans le champ prévu → votre compte est activé.

> 💡 **Conseil :** Si vous ne recevez pas l'e-mail, vérifiez vos **spams / courriers indésirables**.

---

### 🖥️ C. Découvrir la plateforme une fois connecté — parcours guidé

Une fois connecté, vous arrivez sur la **page d'accueil**. Voici exactement où regarder et quoi cliquer.

#### 1. La barre de navigation (en haut de chaque page)

Elle contient plusieurs éléments :

| Élément | Où il se trouve | À quoi il sert |
|---|---|---|
| Logo **VisioConnect** | Tout à gauche | Revenir à l'accueil depuis n'importe quelle page |
| **Fonctionnalités** | Menu du haut | Présentation des capacités de la plateforme |
| **Tarifs** | Menu du haut | Voir les forfaits Free / Pro / Premium |
| **Démo** | Menu du haut | Accéder à la page de démonstration |
| **Se connecter / Mon compte** | Tout à droite | Accéder à votre profil ou vous déconnecter |

#### 2. Sur la page d'accueil `/`

En descendant sur la page, vous verrez :
- Un **bouton principal** pour lancer une démo ou s'inscrire → cliquez dessus pour tester.
- Des **blocs de présentation** des fonctionnalités → faites défiler jusqu'en bas.
- Un **pied de page** avec les liens légaux, réseaux sociaux, contact.

#### 3. Aller sur votre compte

1. Cliquez sur **votre nom** ou l'icône en haut à droite.
2. Un menu déroulant apparaît → cliquez sur **"Mon compte"**.
3. Vous verrez votre adresse e-mail, votre forfait actuel, et les options de gestion.

#### 4. Aller sur la page Tarifs

1. Dans la barre de navigation, cliquez sur **"Tarifs"**.
2. Vous verrez les 3 forfaits : **Free**, **Pro**, **Premium**.
3. Sur chaque forfait, un bouton **"S'abonner"** ou **"Commencer"** est présent → c'est par là que démarre le test Stripe (section 2 de ce guide).

#### 5. Accéder à la page Démo

1. Dans la barre de navigation, cliquez sur **"Démo"**.
2. Vous arriverez sur une page de présentation avec un bouton **"Lancer la démo live"**.
3. Cliquez dessus → une fenêtre vous demande votre **prénom ou pseudo** (pas de compte nécessaire).
4. Saisissez un nom → cliquez sur **"Lancer la démo →"** → vous entrez dans une salle de démonstration.

> 💡 C'est le chemin le plus simple pour tester la visioconférence en solo. Pour tester à deux, partagez l'URL de la salle à un proche.

Notez vos premières impressions visuelles sur chaque page — elles comptent autant que les bugs !

## 💳 2. Tester le système d'abonnement (Stripe)

Nous avons besoin de vous pour tester notre flux de paiement (passage vers un forfait Pro ou Premium).

> **⚠️ Mode TEST activé : aucun argent réel ne sera débité. Il est impossible d'utiliser une vraie carte.**

### Comment accéder à la page de paiement ?

1. Depuis votre tableau de bord, cliquez sur **"Tarifs"** dans le menu.
2. Choisissez le forfait **Pro** ou **Premium**.
3. Cliquez sur **"S'abonner"** — vous serez redirigé vers la page de paiement Stripe.
4. Utilisez l'une des cartes fictives ci-dessous selon le scénario à tester.

> 💡 **Rappel :** après avoir cliqué **"S'abonner"** sur la page Tarifs, Stripe ouvre sa propre page de paiement sécurisée. Saisissez les informations exactement comme indiqué dans chaque scénario ci-dessous.

---

### ✅ Scénario 1 — Paiement réussi *(à tester en priorité)*

C'est le scénario le plus important. Vérifiez que votre compte bascule bien en Premium et que les fonctionnalités avancées sont débloquées.

**Étapes détaillées :**
1. Saisissez exactement les informations ci-dessous dans le formulaire Stripe.
2. Cliquez sur **"Payer"**.
3. Vous devez être redirigé vers une page de confirmation.
4. Revenez sur votre tableau de bord — votre statut doit afficher **"Premium"**.

| Champ | Valeur |
|---|---|
| Numéro de carte | `4242 4242 4242 4242` |
| Date d'expiration | N'importe quelle date future — ex. `12/28` |
| CVC | N'importe quels 3 chiffres — ex. `123` |
| Nom sur la carte | `Testeur VisioConnect` |
| Code postal | N'importe lequel — ex. `75001` |

> Si votre statut ne change pas au bout d'une minute, actualisez la page. Si le problème persiste, c'est un bug à signaler !

---

**Ce qu'on attend :** un message du type *"Votre carte a été refusée"* ou *"Fonds insuffisants"*, avec une invitation à réessayer.

|---|---|

| Date / CVC / Nom | Identiques au scénario 1 |

### 🎥 B. Le cœur technique (visioconférence)

#### Comment démarrer une réunion ? — étapes exactes

**Option A — Via la page Démo (recommandé pour commencer)**
1. Cliquez sur **"Démo"** dans la barre de navigation.
2. Cliquez sur le bouton **"Lancer la démo live"**.
3. Une fenêtre s'ouvre → saisissez votre **prénom ou pseudo** (ex. `Marie`).
4. Cliquez sur **"Lancer la démo →"**.
5. Le navigateur vous demande d'autoriser la **caméra** et le **microphone** → cliquez **"Autoriser"**.
6. Vous êtes dans la salle. Copiez l'URL dans la barre d'adresse et envoyez-la à quelqu'un pour le faire rejoindre.

**Option B — Via votre compte (si disponible)**
1. Connectez-vous et allez sur votre tableau de bord.
2. Cherchez le bouton **"Nouvelle réunion"** ou **"Créer une salle"**.
3. Donnez un nom à la salle ou laissez celui généré automatiquement.
4. Cliquez sur **"Créer"** → autorisez caméra et micro → vous êtes dans la salle.

> 💡 **Testez idéalement à deux** (avec un ami, un collègue, ou un autre testeur bêta) pour valider la qualité vidéo en conditions réelles. Partagez simplement le lien de la salle.

#### Checklist des fonctionnalités à tester

| Fonctionnalité | Comment la tester | Ce qu'on cherche à valider |
|---|---|---|
| **Caméra** | Cliquez sur l'icône caméra pour activer/désactiver | Pas de freeze, image fluide |
| **Microphone** | Cliquez sur l'icône micro pour activer/désactiver | Pas d'écho, son propre |
| **Flou d'arrière-plan** | Bouton « Effets » → ajustez la jauge d'intensité | Flou bien appliqué, pas de ralentissement |
| **Partage d'écran** | Bouton « Partager l'écran » → sélectionnez un onglet | Texte lisible côté participants, pas de décalage |
| **Chat** | Icône bulle → envoyez quelques messages | Messages affichés en temps réel |
| **Tableau blanc** | Bouton « Whiteboard » → dessinez avec au moins une autre personne | Synchronisation instantanée |
| **Quitter la salle** | Bouton rouge « Raccrocher » | Retour propre sur le tableau de bord |

## 🐞 4. Signaler un bug ou proposer une amélioration

> 💬 **Cette section est la plus importante du guide.** Tester sans donner de retour, c'est comme cuisiner un plat et partir sans y goûter. Prenez 5 minutes à la fin de votre session pour m'envoyer un message — vous verrez, c'est rapide.

### ✨ 1. Retours design et expérience utilisateur

Soyez critiques. Je préfère 10 remarques honnêtes à 10 "c'est bien".  
N'hésitez pas à dire spontanément :
- *"Je trouverais ça plus joli si..."*
- *"J'ai eu du mal à trouver comment..."*
- *"Cette page fait un peu vide"*
- *"Ce bouton ne ressemble pas à ce que j'attendais"*
- *"Je ne savais pas si le clic avait fonctionné ou non"*

**Pour les designers parmi vous :** allez plus loin — parlez-moi de hiérarchie visuelle, de contrastes, de cohérence des espacements, de lisibilité sur mobile. Tout ça est exploitable directement.

---

### 🛠️ 2. Signalement de bugs techniques

Si une vidéo fige, qu'un bouton ne répond pas ou qu'une image ne s'affiche pas, merci de fournir les informations suivantes :

1. **Page concernée** — paiement, salle d'attente, tableau blanc…
2. **Matériel utilisé** — PC Windows, Mac, iPhone, Android…
3. **Navigateur** — Chrome version X, Safari, Edge…
4. **Description de l'erreur** — ex. *"J'ai cliqué sur le bouton de la carte 4242... et la page est restée blanche."*
5. *(Optionnel mais précieux)* **Une capture d'écran** ou une photo de la console développeur (`F12` → onglet **Console**).

**Pour les développeurs parmi vous :** si vous repérez une erreur dans la console, copiez-collez le message d'erreur complet dans votre retour — c'est exactement ce dont j'ai besoin pour corriger rapidement.

## ❓ 5. Foire aux questions (FAQ)

**Q. Je suis bloqué sur l'erreur "La caméra est utilisée par une autre application" (Device in Use).**  
→ Assurez-vous d'avoir fermé Microsoft Teams, Zoom, Discord, Google Meet ou OBS. Ces logiciels peuvent monopoliser l'accès à la webcam en arrière-plan.

---

**Q. J'ai simulé le paiement avec la carte 4242... mais mon compte n'a pas changé de statut.**  
→ Les webhooks (le pont entre Stripe et nos serveurs) peuvent parfois prendre quelques secondes à se déclencher en mode test. Actualisez la page au bout d'une minute.

**Q. Dois-je payer quelque chose à la fin de la période de test ?**  
→ Non. Votre compte "Bêta-Testeur" est **100 % gratuit** et vous conserverez les fonctionnalités Premium testées à vie en guise de remerciement.
